# opencursor — frozen contracts (v0)

Single source of truth for parallel builders. **Do not edit this file or any file
under `packages/core/src/protocol/` or `packages/core/src/types.ts`.** If a contract
gap is found, stop and report it instead of changing the contract.

## Environment

- Root: repository root (`opencursor/`)
- Node v22 / npm 10 / tsc 5.7 / tsx 4 (`npx tsc`, `npx tsx` available after root install)
- Windows PowerShell; all code and tests must be cross-platform (run in CI on win32).
- ESM + NodeNext: **relative imports MUST carry `.js` suffixes** (`./foo.js` → resolves `foo.ts`).
- `verbatimModuleSyntax`: use `import type { … }` for type-only imports.
- `noUncheckedIndexedAccess`: index accesses yield `T | undefined` — code defensively.
- **Zero new dependencies** in `@opencursor/core`. Node built-ins + global fetch only.

## v0 tool surface (Builder A)

Implemented + advertised to the model:
`read_file, write_file, str_replace, edit_file, delete_file, grep_search,
file_search, list_dir, run_terminal_cmd, codebase_search, web_search, web_fetch,
update_todos, read_todos, create_plan, read_lints, task, ask_question`

Not implemented in v0 (protocol-declared only): `brainstorm`.

Semantics notes:
- `grep_search`/`file_search`/`codebase_search` shell out to `rg` when available
  (`OPENCURSOR_RIPGREP_PATH` override, then `rg` on PATH);
  `codebase_search` falls back to multi-pattern `rg` and returns a note when no
  embeddings backend is configured.
- `read_lints` v0: if `OPENCURSOR_LINT_CMD` is set, run it per path and map
  stderr lines; otherwise return a success with empty diagnostics + a note via
  `onProgress`.
- `web_search` v0: requires `OPENCURSOR_SEARCH_URL` (POST `{query}` → JSON
  `{results:[{title,url,snippet}]}`); otherwise `error` outcome `not_configured`.
  `web_fetch`: plain fetch + minimal HTML→text/markdown conversion.
- Path args must resolve against `ctx.cwd`; **reject paths escaping the workspace
  root** with `error('permission_denied')` unless the arg path is absolute.
- Mutating tools on Windows must handle `EPERM`/`EBUSY` gracefully.

## Model layer (Builder B)

- `createModelClient` supports `anthropic` (Messages API, streaming SSE) and `openai`
  (Chat Completions, streaming SSE + `tool_calls` deltas). Model ids are never
  hardcoded: they are listed from the provider's `/models` endpoint.
- Normalized events per `ModelStreamEvent`. Tool-call args arrive as raw JSON
  fragments; re-assemble per call id and validate JSON before emitting
  `{type:'tool-call'}` (keep `args_raw`).
- Implement own SSE line parser (no SDK deps); fake-fetch tests must cover
  chunk-split-at-any-byte boundaries, `[DONE]`, and non-JSON keep-alives.
- Base URLs: `ANTHROPIC_BASE_URL` / `OPENAI_BASE_URL` respected.
- `resolveModelConfig`: `config.json` llm block → env; no model id means first from
  `/models`. `detectModelConfig` remains as the sync key-based fallback.

## Runtime semantics (Builder C)

- Loop: user message → model stream → if tool calls: permission gate per call →
  execute (emitting `tool-call-started` / `tool-progress` / `tool-call-completed`) →
  append `tool` message with outcomes → repeat until `stop` ≠ `tool_use` or
  `max_iterations` (then `reason:'max_iterations'`).
- `allow_always` records a rule and skips future asks for matching tool+pattern.
- Event stream: single-consumer async iterable, backpressure-safe; missing
  consumer must not block the turn.
- Session persistence: `SessionState` JSON at `<root>/<id>.json` + `<id>.ndjson`
  ops file; `save` must be atomic-ish (write temp + rename). `latestId` = newest
  by `updated_at`.
- `abort()` cancels in-flight model stream and tools; turn ends
  `reason:'aborted'`.
- Subagent runner: child runtime over an allow-listed tool subset; child events
  are NOT forwarded to the parent stream; returns `SubagentRunResult.summary`
  (last assistant text). `SUBAGENT_PROFILES`: `general` (all), `explore`
  (read-only: read_file, grep_search, file_search, list_dir, codebase_search),
  `shell` (run_terminal_cmd, read_file, list_dir).
- The `task` tool (Builder A) invokes `ctx.subagents.run(profile, …)`;
  unknown profile → `error('invalid_args')`.

## Observed-protocol alignment (Cursor 3.4.20)

Source: `docs/cursor-protocol.md` (full spec + evidence ledger). Static
observation of shipped artifacts only — this section records **what the
observed protocol does** and **what opencursor still owes**.

### Aligned

| Observed | opencursor |
|---|---|
| Per-tool `rejected` / `permission_denied` / `error` triple | `ToolOutcome` union in `protocol/tools.ts` |
| Exec server→host typed args, host→server typed results, out-of-band abort | runtime tool loop + `AgentEvent` stream |
| Pre/PostToolUse interception | `hooks/runner.ts` |
| MCP tools surfaced through the agent tool union | `mcp` tool (`operation: list \| call`) |
| `TASK_MODE_AGENT` / `TASK_MODE_PLAN` | `SessionMode` + `setMode` + plan-mode gate |
| `run_in_background` / `subagent_await` / cancel | `SubagentRunner.start/await/cancel/list` |
| Merkle-diff incremental indexing | `index/` (mtime/hash skip, deleted-file removal) |
| Model ids never hardcoded; listed from provider | `models/` listing + price catalog |

### Gaps to build (ranked)

1. **Canvas SDK** — the only unimplemented blueprint item. Full typed surface is
   in `docs/cursor-protocol.md` §3. Build as `packages/core` canvas registry
   (register/destroy/getUrl, §4) + GUI renderer, with `.canvas.data.json`
   sidecar persistence for `useCanvasState`. **Design constraints are
   load-bearing**: tokens only (no hardcoded hex), no gradients/box-shadows,
   `CardHeader` plain text only, no nested cards.
2. **Sandbox policy** — observed 4 levels
   (`UNSPECIFIED`/`INSECURE_NONE`/`WORKSPACE_READWRITE`/`WORKSPACE_READONLY`)
   plus 12 fields (`network_access`, `additional_readwrite_paths`,
   `additional_readonly_paths`, `debug_output_dir`, `disable_tmp_write`,
   `allowlist_escalated`, `enable_shared_build_cache`, `network_policy`,
   `network_policy_strict`, `capture_denies`, `skip_statsig_defaults`).
   opencursor has a permission engine but no sandbox layer. Next: model the
   policy type and enforce `WORKSPACE_READONLY` / path allowlists.
3. **Mode breadth** — observed 7 `AgentMode` values
   (`AGENT`/`ASK`/`DEBUG`/`MULTITASK`/`PLAN`/`PROJECT`/`TRIAGE`).
   opencursor ships `agent` + `plan`. Next: add `ask` (read-only Q&A) and
   `debug` (hypothesis-driven), which need no new infrastructure.
4. **Skills** — `AgentSkillMetadata` (name, description, globs, plugin,
   marketplace, `disable_model_invocation`) + selection literals
   (`available_skills`, `selected_skills`, `skill_options`). opencursor has
   memory + subagent profiles but no skill loader. Next: load
   `SKILL.md`-style directories, inject selected skill bodies, gate on
   `disable_model_invocation`.
5. **Subagent type registry** — observed 11 types
   (`Bash`, `BrowserUse`, `ComputerUse`, `CursorGuide`, `Custom`, `Debug`,
   `Explore`, `MediaReview`, `Shell`, `VmSetupHelper`, `WatchVideo`).
   opencursor has `general`/`explore`/`shell`. Next: add `debug` and `bash`
   aliases; keep custom subagents declarative (plugin/marketplace provenance).
6. **`apply_patch`** — a model-facing tool literal in the observed set that
   opencursor does not implement (it has `str_replace` + `edit_file`). Next:
   add a unified-diff patch tool for multi-hunk edits.
7. **Hook coverage** — observed also fires on tool **failure**
   (`PostToolUseFailureRequestQuery`) and before compaction
   (`PreCompactRequestQuery`). opencursor runs pre/post only. Next: add the
   failure and pre-compact interception points.
8. **Conversation-state extras** — observed `file_states map<string,bytes>`,
   `turn_timings`, `pending_tool_calls[]`, `plan`, `previous_workspace_uris[]`.
   opencursor persists messages/todos/summary/usage. Next: `file_states` (for
   change-aware context) and `turn_timings` (for the GUI).

### Non-goals (observed but out of scope)

Cloud VM control plane (`anyrun.v1`, `*.cursorvm-manager.com`), telemetry
(`api3.cursor.sh/tev1`), the VS Code workbench fork, and server-side prompt
composition (`root_prompt_messages_json`). opencursor is local-first BYOK.
